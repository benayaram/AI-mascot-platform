# BENAI V4: multilingual assistants and institute lessons

Release `4.0.0-beta.1`, branch `feat/benai-v4-multilingual-institute`.

## What works

- Built-in question answering with the self-hosted Qwen model, streamed text, persistent conversations, spoken replies, microphone turns and explicit interruption. Gemini answers are a separate customer-key choice from Gemini speech. Local fallback is opt-in.
- Saved English, Telugu, Hindi, Tamil, Kannada, Spanish or automatic language selection. English uses Whisper tiny.en; other recognition uses the pinned multilingual Whisper small model, loaded on demand. English Piper remains the natural local voice. Offline eSpeak NG adds inexpensive multilingual speech, including Telugu, with visibly labelled robotic quality.
- Official Google Cloud TTS adapter with voice discovery and Telugu voice names. Existing Gemini/OpenAI/ElevenLabs speech and HeyGen video adapters remain. Experimental Edge voices require `ENABLE_EDGE_TTS=true` in both app and worker. Edge returned HTTP 403 here and is disabled by default.
- Encrypted, tenant-bound customer credentials, stored in MongoDB when Atlas is configured, otherwise SQLite. Separate Gemini answer credentials prevent changing TTS choices accidentally. API keys are never returned to the browser. No paid provider is silently chosen on failure.
- Private TXT/Markdown/text-PDF references with CPU-friendly keyword retrieval, source names in chat, and a source-only answer setting. Public widgets/demos use only the avatar's explicitly configured reference text; they cannot search private workspace uploads. This is bounded lexical retrieval, not vector search or live web browsing.
- Institute editor: editable AI outlines or manual scenes, animated step/cycle cards, an explaining avatar, supporting images/videos, timeline preview, narrated 720p MP4 export, captions and lesson questions with optional spoken explanations.
- Private supporting media, decoded and normalized on upload, owner checks, bounded inventory, authenticated downloads, plan quotas and failure refunds. Each lesson supports 1–6 scenes, 4,000 total narration characters and a maximum three-minute export. Each scene is limited to 60 seconds; CPU neural portrait scenes are limited to six seconds. Supporting video is muted, up to 60 seconds/20 MB; the generated narration supplies sound.
- Customer API routes for knowledge, lessons, teaching media, rendering, questions and downloads. Customer API keys require an eligible plan and stay on the institute's server. This is an institute content integration, not a complete school administration system.
- V3 features remain: admin/customer accounts, plan enforcement, private avatars, CPU/GPU selection, website widgets/SDK, billing adapters, account verification/recovery/privacy, acquisition demos, leads, referrals, monitoring and backup tools.

## Lip movement and rendering quality

V4 changes MuseTalk preprocessing to align the nose/chin crop with the model's training layout. Audio context stays aligned to Whisper's 50 Hz features, and neural output uses 25 fps on CPU and GPU. A smaller, softly feathered mouth/jaw mask preserves more of the original face.

Inspect [the actual neural sample](demo/v4-neural-portrait.mp4) and [fast animation sample](demo/v4-fast-portrait.mp4). Mouth movement is present; phoneme accuracy has not been independently measured. Fast portraits remain audio-driven image warps. Neither path is a cinematic text-to-video model, and neither claims proprietary omni-model quality.

On this five-thread CPU, a 1.2655-second sample took 0.653 seconds in the fast worker and 138.281 seconds in the aligned neural worker. Higher neural frame rate improves temporal smoothness while increasing CPU work. GPU switching requires a real CUDA worker and was not hardware-benchmarked here.

## Run

Use Node 24+, Python 3.12, FFmpeg/ffprobe, Chromium, curl, unzip and Linux x86-64. Preserve `.env` and `.data/.provider-master-key`.

```bash
npm ci --cache /workspace/.npm-cache
# First setup only: cp .env.example .env
npm run setup:local
npm run services:local             # persistent terminal 1
npm run build
npm start                          # persistent terminal 2
npm run lecture:studio             # optional Remotion editor, terminal 3
```

Setup downloads checksum-pinned Whisper small and privately extracts pinned eSpeak NG packages. On other platforms install `espeak-ng` with the OS package manager and use an installed binary or `ESPEAK_NG_BIN`; the private Debian binary requires Linux x86-64/glibc >=2.34. `bash scripts/setup-budget-speech.sh` can be run separately. Runtime/model files remain outside Git in `/workspace/benai-runtime`.

For rendering set `REMOTION_CHROME_PATH` if Chromium is elsewhere. Remotion defaults to one render at a time and shares the video lock with portrait exports. Restarted exports fail visibly with reserved quota recovery; this is a single-instance service, without a distributed queue. Temporary render props embed only the owner's media, so no private files are published in a static Remotion bundle. Caption timing is approximate by sentence/scene, not word alignment.

For Telugu choose **AI & compute → Conversation language → Telugu → Speech provider → Offline multilingual**. For a natural voice, save a Google Cloud or Gemini TTS key and select that provider. Free Gemini quotas depend on Google's current model/account limits; they are not guaranteed by BENAI. Local Qwen's Telugu answer quality and the small Whisper model's recognition need native-speaker evaluation; prefer a stronger configured model for demanding multilingual work.

## Customer institute API

Use `Authorization: Bearer <customer-key>` from a trusted backend. The same endpoints are available under `/api/` for signed-in customers with session/CSRF protection.

| Method             | Endpoint                       | Purpose                                                              |
| ------------------ | ------------------------------ | -------------------------------------------------------------------- |
| GET / POST         | `/api/v1/lessons`              | List or create a lesson                                              |
| POST               | `/api/v1/lessons/generate`     | Generate a reviewed/editable outline; `{topic, avatar_id}`           |
| GET / PUT / DELETE | `/api/v1/lessons/:id`          | Read, edit or remove an owned lesson                                 |
| POST               | `/api/v1/lessons/:id/render`   | Start MP4 export; poll the lesson for status/progress                |
| GET                | `/api/v1/lessons/:id/download` | Private completed MP4                                                |
| GET                | `/api/v1/lessons/:id/captions` | Completed WebVTT captions                                            |
| POST               | `/api/v1/lessons/:id/ask`      | Explain a question using the lesson; `{question}`                    |
| GET / POST         | `/api/v1/lesson-assets`        | List media; upload multipart `file`                                  |
| GET / DELETE       | `/api/v1/lesson-assets/:id`    | Read/remove private supporting media                                 |
| GET / POST         | `/api/v1/knowledge`            | List or add a private source; JSON `{name,text}` or multipart `file` |
| DELETE             | `/api/v1/knowledge/:id`        | Remove a private source                                              |
| POST               | `/api/v1/transcribe`           | Multipart audio with the saved recognition language                  |

Example lesson body:

```json
{
  "title": "The water cycle",
  "avatar_id": "elena",
  "animate_avatar": true,
  "quality": "fast",
  "scenes": [
    {
      "title": "Evaporation",
      "narration": "The sun warms water. Liquid water becomes vapour.",
      "points": ["Heat from the sun", "Liquid becomes gas"],
      "visual": "steps",
      "media_id": null
    }
  ]
}
```

A render uses one video quota unit and speech units based on each scene's narration length. Failed exports refund BENAI reservations; external provider charges cannot be reversed by BENAI. File inventories are atomic and released on deletion. Account export/deletion and offline backups include the new records and local media. R2 object backup still needs a separate policy.

## Budget and remaining work

Use the free plan as a limited trial; sell saved assistants, institute content workflows and integrations. Keep expensive neural rendering optional and capped. Natural external voices/video are billed to customer provider accounts; hosting, storage, mail and compute still have operating costs. See the existing [customer acquisition plan](GROWTH-PLAN.md).

Remotion 4.0.534's included license permits free use by individuals, nonprofits and for-profit organizations with up to three employees; larger commercial organizations need its company license. Review that threshold as the company grows. eSpeak NG is GPL-3.0-or-later and runs as a separate executable; its downloaded packages retain their copyright notices. Whisper small uses the upstream MIT model license. Edge's Python client license does not grant a production SLA for Microsoft's service.

This is a supervised pilot release. Remaining validation includes native-speaker Telugu STT/TTS review, actual customer cloud/provider keys, CUDA performance, public hosting/SMTP/Stripe activation and sustained concurrent load. Full-duplex acoustic barge-in, vector RAG/live search, cinematic generative video, voice cloning, SCORM exports, student rosters/grading and a distributed render queue are not implemented. The API allows an institute to build its own authenticated student interface around these content services.
