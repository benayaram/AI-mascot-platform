# BENAI V2 Avatar SDK

`/sdk.js` renders illustrated SVG rigs and realistic portraits. Realistic rendering shares `/portrait-rig.js` with the React studio, using the self-hosted MediaPipe face model and WASM under `/runtime`. It warps a local photo mesh from audio levels; it does not run MuseTalk in the browser or generate neural live frames.

```html
<div id="avatar" style="width:280px;height:280px"></div>
<script type="module">
  import { BENAIAvatar } from "/sdk.js";
  const avatar = new BENAIAvatar(document.querySelector("#avatar"), {
    name: "Milo",
    image: "/realistic/milo.png",
    gesture: true,
  });
  avatar.on("ready", () => console.log("Face rig loaded"));
  avatar.on("state", (state) => console.log(state));
  avatar.on("error", (error) => console.error(error));
  // After a user gesture:
  // await avatar.speak('/your-server/generated-speech.wav');
  // Or accept audio from your own voice agent:
  // await avatar.connectStream(remoteMediaStream);
  // avatar.stop();
  // avatar.destroy();
</script>
```

For illustrated rigs, use `/avatars/nova.svg` and `glasses`, `suitColor`, `hairColor`. Those appearance properties do not change photographs. Front-facing, clear single-person photos work best. If the detector cannot find a face, the SDK emits an error and retains a static portrait; do not present it as successful rigging.

For your own host, copy the module, portrait helper, permitted image, and prepared runtime assets to that host. The public module assumes same-origin `/runtime` assets. Follow the models' licenses. The official browser task model/WASM assets are generated by `npm run setup:local`; they are not committed binaries. Permit `'wasm-unsafe-eval'` in the script CSP for trusted MediaPipe WebAssembly compilation; no general JavaScript `'unsafe-eval'` is required.

The iframe widget is the easiest hosted integration. Its revocable embed ID accesses only that avatar's chat/speech/image. Private portraits use the scoped embed image route, not an exposed account key. API keys belong on the customer's server. A user gesture may be needed for AudioContext playback. `connectStream()` plays the incoming stream, so do not route it to speakers twice.

Live face animation is capped near 30 updates/second in this CPU-friendly renderer and is amplitude-driven. It does not provide 120 fps or phoneme-accurate visemes. Actual neural lips are provided by the server's queued MuseTalk exports, subject to measured CPU latency and crop/blending quality.
