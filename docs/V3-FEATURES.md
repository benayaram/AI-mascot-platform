No external provider key is returned from the vault. Saving a key does not prove model/account access: test authenticated discovery, then run a short preview on your own account. Preview and video generation can incur the provider’s charges. BENAI quotas remain enforced even with customer keys.

HeyGen requires avatar and voice IDs from the customer’s HeyGen account. Local portrait uploads do not create HeyGen avatars. Gemini TTS streaming is speech synthesis after the BENAI conversation reply; it is not a full Gemini Live multimodal conversation or automatic full-duplex barge-in.

CPU fast animation stretches portrait pixels using audio amplitude. Neural MuseTalk is a different quality/computation path. The fast renderer’s latency cannot be quoted as MuseTalk latency.

Public hosting, business identity/legal review, real payment/provider/cloud-account activation, chosen-host load testing and GPU benchmarking require the actual deployment and accounts. The code supplies those integration workflows; local fixtures are not evidence that an absent account is connected.
